# Contributing

Thanks for helping! Bugs, ideas and pull requests are welcome.

- **Bugs:** open an issue with your OS, the file type you opened and what you expected. A small MIDI/project that shows the problem helps a lot.
- **Pull requests:** keep them focused. Run the tests first (see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)) and add a test for new behavior when you can.
- **Style:** match the code around you. Scripts are GDScript for Godot 4.7.
- **Icons:** they are authored in `assets/branding/make_icons.py`; edit there and run it, don't edit `scripts/core/icon_data.gd` by hand.
- **License:** this project is GPLv3. By contributing you agree your work is released under it. Don't add music, soundfonts or pictures you don't have the rights to.
