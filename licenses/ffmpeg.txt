The Mac app includes ffmpeg (https://ffmpeg.org), used to write MP4 videos.
Build: https://ffmpeg.martin-riedl.de (macOS, static, GPL configuration).
ffmpeg is licensed under the GNU GPL version 3 (this build includes GPL
components such as x264). Its source code is available from
